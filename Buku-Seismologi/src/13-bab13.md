## 13.1 Data, metadata, dan cara memperolehnya

**Format data.** Data bentuk gelombang seismologi disimpan dalam format
**miniSEED**, yaitu deret cacahan terkompresi beserta informasi waktu,
diidentifikasi oleh empat kode: jaringan, stasiun, lokasi, dan kanal (misalnya
`GE.UGM..BHZ`). Kode kanal bersifat baku: huruf pertama menyatakan pita dan
laju cuplik (B = pita lebar, H = laju tinggi, L = laju rendah), huruf kedua
menyatakan jenis instrumen (H = seismometer kecepatan, N = akselerometer), dan
huruf ketiga menyatakan orientasi (Z, N, E).

**Metadata.** Tanggapan instrumen dan informasi stasiun disimpan dalam
**StationXML**. Tanpa metadata, data bentuk gelombang tidak dapat diubah
menjadi gerakan tanah — jadi metadata bukan pelengkap, melainkan bagian dari
datanya.

**Katalog.** Parameter gempa dipertukarkan dalam format **QuakeML**.

**Layanan data.** Hampir semua pusat data dunia menyediakan **FDSN web
services** dengan antarmuka seragam: `dataselect` untuk bentuk gelombang,
`station` untuk metadata, dan `event` untuk katalog. Pusat data yang relevan
bagi mahasiswa Indonesia antara lain GEOFON (GFZ), EarthScope, ISC, dan
repositori data gempa BMKG.

## 13.2 ObsPy: peralatan dasar

**ObsPy** adalah pustaka Python untuk seismologi yang telah menjadi standar de
facto. Berikut kerangka alur kerja yang paling sering dipakai. Contoh kode
ditulis agar dapat dijalankan mahasiswa langsung.

**Memuat dan menampilkan data.**

```python
from obspy import read
st = read("data/*.mseed")     # atau read() untuk contoh bawaan
print(st)
st.plot()
```

**Prapengolahan baku.**

```python
st.merge(method=1, fill_value="interpolate")
st.detrend("linear")
st.taper(max_percentage=0.05, type="hann")
st.filter("bandpass", freqmin=0.05, freqmax=2.0,
          corners=4, zerophase=True)
```

Urutannya penting: pembuangan tren dan penerapan *taper* sebelum penapisan
mencegah gejala tepi yang dapat menyerupai fase gelombang.

**Koreksi instrumen** (lihat Subbab 2.7).

```python
from obspy import read_inventory
inv = read_inventory("stasiun.xml")
st.remove_response(inventory=inv, output="VEL",
                   pre_filt=(0.005, 0.01, 20.0, 25.0))
```

Parameter `pre_filt` adalah penapis prawatas yang mutlak diperlukan; tanpa itu
derau pada frekuensi tempat instrumen tidak peka akan diperkuat tak terkendali.

**Waktu tempuh teoretis.**

```python
from obspy.taup import TauPyModel
model = TauPyModel(model="ak135")
arr = model.get_travel_times(source_depth_in_km=10.0,
                             distance_in_degree=0.5,
                             phase_list=["p", "s", "P", "S"])
for a in arr:
    print(f"{a.name:5s} {a.time:8.2f} s  "
          f"sudut tinggal landas {a.takeoff_angle:6.2f}")
```

Potongan kode inilah yang menggantikan tabel Jeffreys–Bullen dan globe pada
Bab 3 dan Bab 4.

**Mengunduh data dari pusat data.**

```python
from obspy.clients.fdsn import Client
from obspy import UTCDateTime
client = Client("GFZ")           # atau "IRIS", "EMSC", dll.
t = UTCDateTime("2006-05-26T22:53:58")
st = client.get_waveforms("GE", "*", "*", "BH*",
                          t - 60, t + 900, attach_response=True)
```

**Menggambar bola fokus.**

```python
from obspy.imaging.beachball import beachball
beachball([48, 89, -178])        # strike, dip, rake
```

**Kotak 13.1 — Kesalahan yang paling sering terjadi.**

1. **Lupa koreksi instrumen** lalu menghitung magnitudo dari cacahan. Hasilnya
   tidak bermakna secara fisis.
2. **Menapis sebelum membuang tren**, sehingga muncul gejala tepi yang terbaca
   sebagai fase palsu.
3. **Memakai penapis satu arah** (`zerophase=False`) lalu menganggap waktu
   tiba tidak bergeser. Penapis kausal menggeser fase; untuk *picking* yang
   teliti gunakan `zerophase=True` atau lakukan *picking* pada data mentah.
4. **Mengabaikan pemeriksaan kualitas pewaktuan** (Bab 2).
5. **Memakai data di bawah magnitudo kelengkapan** dalam analisis statistik
   (Bab 8).

## 13.3 Deteksi dan penentuan fase otomatis

**STA/LTA.** Pendeteksi klasik membandingkan rata-rata jangka pendek (*short
time average*) dengan rata-rata jangka panjang (*long time average*) dari
suatu fungsi ciri:

$$r(t) = \frac{\mathrm{STA}(t)}{\mathrm{LTA}(t)} \text{~~~~~~~~~~~~~~~~} (13.1)$$

Pemicuan terjadi bila $r$ melampaui ambang tertentu. Metode ini sederhana,
cepat, dan masih menjadi tulang punggung sistem operasional. Kelemahannya:
kepekaannya rendah untuk sinyal yang terbenam derau, dan ambangnya harus
disetel untuk tiap stasiun.

```python
from obspy.signal.trigger import classic_sta_lta, trigger_onset
tr = st.select(component="Z")[0]
cft = classic_sta_lta(tr.data, int(1*tr.stats.sampling_rate),
                      int(20*tr.stats.sampling_rate))
onsets = trigger_onset(cft, 3.5, 1.5)
```

**Pendeteksi berbasis pembelajaran mesin.** Sejak sekitar 2018, jaringan saraf
dalam telah mengubah tahap ini secara mendasar. Model seperti **PhaseNet** dan
**EQTransformer**, yang dilatih pada jutaan bentuk gelombang berlabel,
melakukan deteksi kejadian dan penentuan waktu tiba fase P dan S sekaligus,
dengan kepekaan jauh melampaui STA/LTA dan ketelitian yang setara pemilih
manual berpengalaman.

Dampak praktisnya besar: pengolahan ulang katalog lama dengan model semacam
ini secara rutin menghasilkan **sepuluh kali lebih banyak kejadian**
dibandingkan katalog aslinya. Untuk data gempa susulan seperti data Yogyakarta
2006, pengolahan ulang semacam ini adalah salah satu arah penelitian yang
terbuka bagi mahasiswa Indonesia hari ini, karena datanya sudah ada dan
tinggal diolah dengan alat yang belum ada ketika data itu direkam.

Dua peringatan yang perlu disampaikan sejak awal: model yang dilatih pada data
suatu wilayah tidak selalu bekerja baik di wilayah lain, dan keluaran model
tetap harus diperiksa secara manual pada sebagian sampel sebelum dipercaya.

## 13.4 Korelasi silang dan pencocokan templat

Gempa yang terjadi pada bidang sesar yang sama dengan mekanisme yang sama akan
menghasilkan bentuk gelombang yang **sangat mirip** di stasiun yang sama.
Kemiripan ini dapat dimanfaatkan dengan dua cara.

**Pengukuran selisih waktu yang sangat teliti.** Korelasi silang antara dua
bentuk gelombang memberikan selisih waktu tiba dengan ketelitian jauh di bawah
satu cuplikan (melalui interpolasi puncak korelasi). Selisih inilah yang
menjadi masukan bagi relokasi beda-ganda (Subbab 4.3.4), dan yang membuat
ketelitian relatif hiposenter mencapai puluhan meter.

**Pencocokan templat** (*template matching* atau *matched filter*). Sebuah
bentuk gelombang gempa yang sudah dikenal dipakai sebagai templat, lalu
dikorelasikan secara menerus dengan rekaman panjang. Setiap puncak korelasi
yang melampaui ambang menandakan kejadian dengan bentuk gelombang serupa —
termasuk kejadian yang jauh terbenam di dalam derau dan tidak akan pernah
terdeteksi STA/LTA. Metode ini dapat menurunkan magnitudo kelengkapan sebesar
satu satuan atau lebih.

## 13.5 Alur kerja yang dapat diulang

Bagian ini singkat tetapi penting, dan berlaku untuk skripsi maupun publikasi.

- **Simpan data mentah tanpa diubah.** Semua pengolahan dilakukan oleh skrip
  yang menghasilkan data olahan; jangan pernah menimpa data asli.
- **Tulis skrip, bukan langkah manual.** Pengolahan yang dikerjakan dengan
  klik tidak dapat diulang dan tidak dapat diperiksa.
- **Kendalikan versi.** Simpan skrip dalam sistem kendali versi.
- **Catat parameter.** Frekuensi penapis, ambang, model kecepatan, dan versi
  perangkat lunak dicatat dalam berkas konfigurasi, bukan disembunyikan di
  dalam kode.
- **Sertakan pemeriksaan.** Gambar hasil antara — bukan hanya hasil akhir —
  agar kesalahan tertangkap lebih awal.
- **Arsipkan.** Data dan skrip yang tersimpan rapi akan bernilai bertahun-tahun
  kemudian, seperti diperlihatkan kasus MERAMEX pada Kotak 6.1.

**Ringkasan Bab 13**

1. Format baku: miniSEED untuk bentuk gelombang, StationXML untuk metadata,
   QuakeML untuk katalog; semuanya diperoleh lewat FDSN web services.
2. ObsPy menyediakan seluruh alur kerja dasar: pembacaan, prapengolahan,
   koreksi instrumen, waktu tempuh teoretis, dan penggambaran.
3. Urutan prapengolahan (buang tren → taper → tapis) dan penapis prawatas pada
   koreksi instrumen adalah dua hal yang paling sering salah.
4. STA/LTA masih menjadi tulang punggung operasional; pendeteksi berbasis
   pembelajaran mesin meningkatkan kepekaan secara mendasar.
5. Korelasi silang memberikan selisih waktu berketelitian tinggi; pencocokan
   templat menurunkan magnitudo kelengkapan.
6. Alur kerja berbasis skrip, terdokumentasi, dan terarsip adalah bagian dari
   mutu penelitian.
:::
