**Catatan tentang sumber data dan laman resmi**

Selain pustaka di atas, buku ini merujuk pada data dan dokumentasi yang
tersedia daring dari lembaga-lembaga berikut. Karena alamat laman dapat
berubah, yang dicantumkan adalah nama lembaganya.

- **BMKG** — katalog gempa, repositori data gempa, informasi InaTEWS, dan
  penjelasan skala intensitas SIG-BMKG.
- **Badan Geologi / PVMBG** — informasi aktivitas gunung api dan tingkat
  kewaspadaan.
- **Pusat Studi Gempa Nasional (PuSGeN)** — peta sumber dan bahaya gempa.
- **GEOFON, GFZ Potsdam** — data bentuk gelombang, termasuk arsip proyek
  MERAMEX.
- **EarthScope Consortium** — data Global Seismographic Network.
- **International Seismological Centre (ISC)** — buletin gempa global.
- **Global CMT Project** — katalog tensor momen.
- **USGS Earthquake Hazards Program** — katalog gempa dan ShakeMap.

Pengguna data wajib memeriksa dan mencantumkan ketentuan sitasi masing-masing
penyedia data.
:::
